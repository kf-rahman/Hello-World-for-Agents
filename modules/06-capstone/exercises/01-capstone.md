## Purpose
Put the whole course together on one task.

## Guide instructions
Describe the `P6.1` task, then guide the learner through these stages one turn
at a time. Coach them, but don't do their part.

1. **Specify (Module 1):** they write `workspace/prompts/6.1.md` using Goal,
   Context, Constraints, Done when.
2. **Plan (Module 1):** they get a plan from the agent, review it, and approve it.
3. **Carry out (Modules 2–4):** the agent does the work. The learner keeps
   `workspace/AGENTS.md` up to date if they learn anything new, uses their
   skill if it applies, and uses the MCP server if the task needs it.
4. **Verify:** the project's verification passes.
5. **Reflect (Module 5):** they write `workspace/RETRO.md` with short answers:
   - Where did the agent save you the most time?
   - Where did it need your judgment?
   - Which surface would you use for this task at work, and why?
   - What will you do differently next time?

When they pass, show a short completion summary: modules completed, total
time, and hints used.

## Learner steps
1. Specify → plan → carry out → verify → reflect.

## Completion check
- `workspace/prompts/6.1.md` covers all four parts.
- The `P6.1` task is complete and the project's verification passes.
- `workspace/RETRO.md` answers all four questions.

## Hints
1. Go back to earlier modules if needed: specific prompt (1.1), plan first
   (1.2), memory file (2.2).
2. If the session gets long or cluttered, do a handoff (2.3).

## Takeaway
You've taken a task from a written spec to a verified result with an agent.
That's the core workflow; the rest is practice.
