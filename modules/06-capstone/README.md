# Module 6: Capstone

**Time:** 20 minutes

## Learning goal
The learner completes a realistic task from start to finish with an agent,
applying every module, and reflects on where the agent helped and where they
were needed.

## Objectives
- Plan, carry out, and verify a multi-step task (Modules 1 and 2).
- Use the project's memory file and skill (Modules 2 and 3).
- Use MCP where it fits (Module 4).
- Explain which surface they'd use for this task in real work (Module 5).

## Persona notes
- **Engineer:** the `P6.1` task is a small feature or fix that touches several files.
- **Business:** the `P6.1` task is a deliverable (for example, a report or
  analysis) built from several sources.
