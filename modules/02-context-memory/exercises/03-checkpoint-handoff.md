## Purpose
Pause a task partway, write a handoff note, and have a new session finish the
task using only the note and the files.

## Guide instructions
1. Describe the `P2.2` task. The learner starts it with the agent in this
   session.
2. About halfway through, stop and ask the learner to have the agent write
   `workspace/HANDOFF.md`: the goal, what's done, what's left, the decisions
   made and why, and how to verify the result.
3. The learner reviews the note and edits anything that's missing.
4. The learner opens a **new session** and says only: "Continue the task in
   workspace/HANDOFF.md."
5. Back here, `check` the result.

## Learner steps
1. Start the task.
2. Get a handoff note written and review it.
3. Finish the task in a new session using only the note.

## Completion check
- `workspace/HANDOFF.md` includes the goal, the remaining steps, the decisions
  made, and how to verify the result.
- The `P2.2` task is complete and the project's verification passes.

## Hints
1. Would a colleague who wasn't here understand the note?
2. The "decisions and why" section is what's most often missing.

## Takeaway
A fresh session with a good note often does better than a long, cluttered one.
This is how you take on work that's too large for one session.
