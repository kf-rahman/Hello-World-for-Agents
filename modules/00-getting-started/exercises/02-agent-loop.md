## Purpose
See the agent loop happen live, and see that the agent gathers facts before it
answers.

## Guide instructions
Ask the learner to give you the `P0.1` task from their project, in their own
words. It should be something like "Look at the project in workspace/ and tell
me what it does."

While you do the task, **narrate each step in one line before you take it**,
for example "Reading the data file to see which columns it has." When you finish,
say how many actions you took.

Then ask: *"How many actions did I take, and which one would a chatbot have been
unable to do?"*

## Learner steps
1. Ask the agent to do task `P0.1`.
2. Answer the follow-up question.

## Completion check
The learner saw at least two tool actions and answered the question in their own
words.

## Hints
1. No special wording is needed. Ask in plain English.
2. Example: "What's in the workspace folder? Explain it to me."

## Takeaway
**Read → decide → act → observe → repeat.** The agent checked the files
instead of guessing. That's what makes agents useful, and it's also why you
should watch what they do.
