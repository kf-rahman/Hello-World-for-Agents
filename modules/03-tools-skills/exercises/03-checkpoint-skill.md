## Purpose
Confirm the skill works: a new session should use it without being told to.

## Guide instructions
The learner opens a **new session** and asks for the `P3.1` outcome in ordinary
words, *without naming the skill*. (Example: "Can you put together this week's
report?") They come back and tell you whether the skill was used. Most tools
show when a skill is loaded.

If it wasn't used, help them improve the description and try again.

## Learner steps
1. In a new session, ask for the outcome without naming the skill.
2. Report what happened, and improve the description if needed.

## Completion check
A new session used the skill, and the `P3.1` result passes the project's
verification.

## Hints
1. If the skill wasn't used, compare the words you used in your request with
   the words in the description.

## Takeaway
If the agent picks up a skill without being told, its description is doing its
job. Descriptions work like prompts.
