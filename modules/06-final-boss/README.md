# Module 6: Final Boss

> *The Dragon of Technical Debt has taken the Tavern Ledger. Everything you've
> learned comes into play now.*

## Challenge (draft)
Turn the Tavern Ledger into something a real tavern could use. Suggested
feature: **multiple taverns + a daily sales report**. The player must:

1. **Prompting:** write a GCCD spec in `playground/prompts/final.md` and get a
   reviewed plan before any code.
2. **Context:** keep `playground/AGENTS.md` up to date and do at least one
   deliberate fresh-session handoff.
3. **Tools & Skills:** use or extend their release skill to ship the change.
4. **MCP:** expose the new report through their ledger MCP server (optional
   for novices).
5. **Reflection:** write `playground/RETRO.md`: what the agent was good at,
   where it needed them, and what they'd do differently.

## Win condition (draft)
All tests pass, the feature works end to end, and the GM reviews `RETRO.md`
against the module objectives. Award a completion "certificate" (ASCII art).
