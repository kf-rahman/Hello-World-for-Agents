# Module 5: The Tool Landscape

> *The guild hall. Adventurers from rival guilds argue over whose sword is best.
> The answer, as always: it depends on the quest.*

## Learning objectives
- Map the landscape by **form factor**, not brand:
  - **Terminal agents:** Claude Code, OpenAI Codex CLI, Gemini CLI, and others
  - **IDE agents:** Cursor, Windsurf, GitHub Copilot agent mode, and others
  - **Cloud/async agents:** agents that run in a remote sandbox and open a PR
    (for example Claude Code on the web, Codex cloud, Copilot coding agent)
- Compare on the things that matter: autonomy and permission model, memory-file
  conventions, extensibility (skills, MCP, hooks), model choice, pricing, and
  where it runs.
- See what **carries over** between tools: prompting, memory files, MCP, and
  (increasingly) skills. Learn the ideas once and switch tools freely.

## Key ideas (draft)
- Most concepts in Modules 1 to 4 are **tool-independent**. That's the main point.
- `AGENTS.md` is a shared convention read by many tools; some tools use their
  own file name or can import `AGENTS.md`.
- **This landscape changes monthly.** The comparison table lives in
  `docs/landscape.md` (to be written) with a "last checked" date, and the GM
  must tell players to check official docs.
